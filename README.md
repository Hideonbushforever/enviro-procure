# EnviroProcure

**环保设备采购比选工具 · Water-treatment equipment procurement comparison**

[English](README.en.md) · [第一次上传 GitHub](docs/START_HERE.zh-CN.md) · [计算方法](docs/METHODOLOGY.md) · [开发计划](docs/ROADMAP.md)

把水处理设备的采购报价、运行参数、交期、质量和风险放进一个可解释的比较框架。

这是一个 **v0.1.0 起步项目**：可在浏览器本地运行，使用虚构示例数据。当前没有真实客户部署、节省金额或用户规模的声明。

## 快速开始

1. 下载并解压项目，保持文件夹结构完整。
2. 用 Chrome、Edge 或 Firefox 打开 `index.html`，无需安装依赖。
3. 调整项目口径和供应商数据。输入框失去焦点后，结果自动更新。
4. 导出 **CSV** 在 Excel 中查看；导出 **JSON** 保存全部输入，之后可重新导入。

本工具没有服务器、账户、统计追踪或外部字体。数据留在当前浏览器的本地存储中；更换浏览器、清理记录或移动本地文件，可能无法读取原记录，请用 JSON 备份。

## 能做什么

| 功能 | 用途 |
| --- | --- |
| 项目口径 | 统一处理量、运行天数、电价、评估期及币种 |
| 成本测算 | 分开展示采购交付费、年电费、年药剂费、年维护费和评估期总成本 |
| 硬性要求筛选 | 技术核验、交付日期与最低质保不满足时保留测算，但不参与排名 |
| 可解释评分 | 成本、质量、交期、服务权重可调，显示各分项得分 |
| 风险跟进 | 记录概率、影响、应对和跟进人 |
| 导入与导出 | 项目 JSON 导入导出、结果 CSV 导出、浏览器打印 |

支持 1–12 家供应商；支持 CNY、USD、AUD、EUR 的显示，**不进行汇率换算**。每个项目内所有金额必须已统一币种与税费口径。

## 为什么做这个项目

水处理与工程管理知识可以帮助识别工况、运行费用和交付约束；市场分析与商务支持需要把这些信息转成可比较、可解释的客户方案。本项目将这些任务落成一个可反复使用的小工具。

采购谈判和供应商协调经验也可以沉淀为“依据、条件、风险、负责人”的结构化记录。工具适用于前期方案讨论与学习演示；技术状态及评分仍需使用者依据资料核验。

## 示例与边界

内置 A、B、C 三家供应商均为虚构示例。示例 C 的设备报价较低，但超过交期要求；示例 B 的初始投入较高，假设运行费用较低，因此在当前输入下评估期成本较低。

示例采用 1,000 m³/天、330 天/年、5 年评估期。计算结果：

| 方案 | 采购与交付 | 年运行费用 | 5 年总成本 | 筛选 |
| --- | ---: | ---: | ---: | --- |
| A | 260,000 | 115,620 | 838,100 | 通过 |
| B | 305,000 | 89,190 | 750,950 | 通过 |
| C | 223,000 | 141,060 | 928,300 | 交期超出 15 天 |

金额单位为 CNY，仅用于核对程序计算。模型按固定年费用累加，未考虑折现、价格变化、融资、残值、税费差异、停机、人工或大修费用。它不预测处理效果，不自动判断排放达标，也不构成采购批准。

## 开发与验证

计算逻辑与界面分开，核心逻辑不依赖浏览器。

```sh
npm test
```

测试需要 Node.js 22 或以上，无需 `npm install`。普通使用者打开 `index.html` 即可。

```text
enviro-procure/
  index.html                 页面入口
  assets/engine.js            验证、成本、筛选、评分、CSV
  assets/app.js               界面、导入导出、本地保存
  assets/demo.js              明确标识的虚构示例
  assets/styles.css           响应式与打印样式
  examples/demo-project.json  可导入示例
  tests/engine.test.js        核心逻辑测试
  docs/                      上手、方法、开发计划
  .github/                   持续测试与问题模板
```
